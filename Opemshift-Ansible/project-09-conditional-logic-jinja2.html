01 The Manager's Ninth Ticket — INFRA-2002

🏢 ABC Bank OpenShift Platform Team — Intermediate Week 2

The universal deployment role from Project 08 is working. Now Rajesh brings an evolution ticket:

"The role is good but it's too rigid. Some apps need sidecars (only in PROD). Some namespaces need NetworkPolicy (only in QA and above). The health report should show different metrics for DEV vs PROD. The email should only fire when there are failures — not every run. Some tasks should skip entirely in DEV but run in PROD. Right now the playbook either runs everything or nothing. Can you make the automation intelligent — able to make decisions?"

This ticket forces us to add intelligence: tasks that conditionally run, templates that adapt their output, and Jinja2 that transforms data mid-flight. This is what separates junior from senior automation engineers.

02 when: Conditions — Task-Level Intelligence

The when keyword is Ansible's primary conditional. It evaluates a Jinja2 expression. If true → task runs. If false → task is skipped (shown as skipping in output, not an error).

yaml when: — All Forms and Patterns 
---
# FORM 1: Simple equality check

- name: "Only run in PROD"
  ansible.builtin.debug:
    msg: "This is production"
  when: environment_name == "prod"

# FORM 2: Negation — NOT

- name: "Skip in DEV"
  ansible.builtin.debug:
    msg: "Not DEV"
  when: environment_name != "dev"

# FORM 3: List = implicit AND (all must be true)

- name: "Only in PROD and only when health is low"
  ansible.builtin.include_tasks:
    file: send_critical_alert.yml
  when:
    - environment_name == "prod"
    - health_score | int < 80    # Both must be true

# FORM 4: OR logic (use Jinja2 'or')

- name: "Run in QA or UAT"
  ansible.builtin.debug:
    msg: "Testing environment"
  when: environment_name == "qa" or environment_name == "uat"

# FORM 5: 'in' operator — membership test

- name: "Run if env is one of prod or dr"
  ansible.builtin.debug:
    msg: "High-stakes environment"
  when: environment_name in ['prod', 'dr']

# FORM 6: Check if variable is defined

- name: "Only if sidecar image is defined"
  ansible.builtin.debug:
    msg: "Sidecar enabled"
  when: sidecar_image is defined

# FORM 7: Check registered result

- name: "Check if namespace exists"
  kubernetes.core.k8s_info:
    kind: Namespace
    name: "{{ app_namespace }}"
  register: ns_check

- name: "Create namespace only if missing"
  kubernetes.core.k8s:
    state: present
    definition: "{{ lookup('template', 'namespace.yml.j2') }}"
  when: ns_check.resources | length == 0

# FORM 8: Check command output

- name: "Run command"
  ansible.builtin.command:
    cmd: "oc get node worker01 -o jsonpath='{.status.conditions[-1].type}'"
  register: node_status
  changed_when: false

- name: "Alert only if node not Ready"
  ansible.builtin.debug:
    msg: "Node is NOT ready"
  when: node_status.stdout != 'Ready'

03 Complex Conditions — Boolean Algebra in Ansible

yaml Complex when: — AND, OR, NOT, Nested 
# PATTERN: Complex multi-condition (parentheses for clarity)

- name: "Deploy sidecar only in prod AND if explicitly enabled"
  kubernetes.core.k8s:
    state: present
    definition: "{{ lookup('template', 'sidecar.yml.j2') }}"
  when:
    - environment_name == "prod"
    - enable_sidecar | default(false) | bool     # Cast to bool

# PATTERN: Skip if either condition is true (negate OR)

- name: "Skip in DEV or if maintenance window active"
  ansible.builtin.include_tasks:
    file: deploy_steps.yml
  when:
    - environment_name != "dev"
    - not maintenance_window_active | default(false) | bool

# PATTERN: Check list emptiness

- name: "Alert only if there are failed pods"
  community.general.slack:
    token: "{{ vault_slack_token }}"
    msg:   "Failed pods: {{ failed_pods | length }}"
  when: failed_pods | length > 0

# PATTERN: String contains check

- name: "Run if image tag is a release (not SNAPSHOT)"
  ansible.builtin.debug:
    msg: "Release build"
  when: "'SNAPSHOT' not in app_image_tag"

# PATTERN: Numeric comparison with filter

- name: "Scale up if replicas below minimum"
  kubernetes.core.k8s:
    state: present
    definition:
      apiVersion: apps/v1
      kind: Deployment
      spec:
        replicas: 3
  when:
    - current_replicas | int < min_replicas | default(3) | int
    - environment_name in ['prod', 'dr']

# PATTERN: failed_when — override what counts as failure

- name: "Check if route exists (ok if not found)"
  ansible.builtin.command:
    cmd: "oc get route payment-api -n {{ app_namespace }}"
  register: route_check
  failed_when:  false       # Never fail this task (rc=1 = not found = OK)
  changed_when: false       # Read-only, never mark as changed

- name: "Create route only if not found"
  kubernetes.core.k8s:
    state: present
    definition: "{{ lookup('template', 'route.yml.j2') }}"
  when: route_check.rc != 0

04 block + when — Conditional Groups of Tasks

Applying when to every task is verbose. Use block to group tasks and apply a single when to the entire block. The condition is evaluated once; all tasks inside share it.

yaml block with when — Conditional Task Groups 
---
# Apply single condition to a block of 5 tasks


- name: "PROD-only: NetworkPolicy + PodDisruptionBudget + SecurityContext"
  block:

    - name: "Create NetworkPolicy"
      kubernetes.core.k8s:
        state: present
        definition: "{{ lookup('template', 'network_policy.yml.j2') }}"

    - name: "Create PodDisruptionBudget"
      kubernetes.core.k8s:
        state: present
        definition: "{{ lookup('template', 'pdb.yml.j2') }}"

    - name: "Apply SecurityContextConstraints"
      ansible.builtin.command:
        cmd: "oc adm policy add-scc-to-serviceaccount restricted-v2 -z {{ app_name }} -n {{ app_namespace }}"

    - name: "Send deployment notification to compliance team"
      community.general.mail:
        to:      ["compliance@abcbank.com"]
        subject: "PROD Deployment: {{ app_name }}:{{ app_image_tag }}"
        body:    "{{ lookup('template', 'compliance_email.j2') }}"

  when: environment_name == "prod"   # All 4 tasks above skip if not PROD

# DEV-only block
- name: "DEV-only: seed test data and disable auth"
  block:
    - name: "Apply test data ConfigMap"
      kubernetes.core.k8s:
        state: present
        definition: "{{ lookup('template', 'test_data.yml.j2') }}"

    - name: "Disable auth for local development"
      kubernetes.core.k8s:
        state: present
        definition:
          apiVersion: v1
          kind: ConfigMap
          metadata:
            name: auth-override
            namespace: "{{ app_namespace }}"
          data:
            AUTH_DISABLED: "true"

  when: environment_name == "dev"

05 Jinja2 Filters — Complete Production Reference

Type Conversion & Safety Filters

jinja2 Type, Safety, and String Filters 
# TYPE CONVERSION
{{ app_replicas | int }}          # "3" → 3 (integer)
{{ cpu_limit | float }}          # "1.5" → 1.5
{{ enable_sidecar | bool }}     # "true"/"True"/"yes"/1 → True
{{ health_score | string }}    # 95 → "95"
{{ data | to_json }}           # dict/list → JSON string
{{ data | to_yaml }}           # dict/list → YAML string
{{ json_str | from_json }}     # JSON string → dict/list

# SAFETY FILTERS
{{ some_var | default('fallback') }}            # Use 'fallback' if var undefined
{{ some_var | default(omit) }}                  # Omit key entirely if undefined
{{ some_var | default('') | length > 0 }}      # Safe length check
{{ some_var is defined }}                        # True if variable exists
{{ some_var is not defined }}                    # True if variable missing
{{ some_var | mandatory }}                       # Fail if undefined (explicit)

# STRING FILTERS
{{ environment_name | upper }}    # "prod" → "PROD"
{{ app_name | lower }}           # "PaymentAPI" → "paymentapi"
{{ app_name | capitalize }}     # "payment" → "Payment"
{{ app_name | replace('-', '_') }}  # "payment-api" → "payment_api"
{{ message | truncate(80) }}    # Trim to 80 chars with "..."
{{ text | trim }}               # Strip whitespace
{{ words | join(', ') }}        # ['a','b'] → "a, b"
{{ phrase | split(' ') }}       # "hello world" → ['hello','world']

# REGEX (most powerful string ops)
{{ version | regex_search('^v(\d+\.\d+)') }}   # Extract semver
{{ url | regex_replace('https?://', '') }}      # Strip protocol
{{ tag | regex_search('SNAPSHOT') is not none }} # Contains check

List & Dict Transformation Filters

jinja2 List and Dict Power Filters 
# LIST FILTERS
{{ pods | length }}                                # Count items
{{ pods | first }}                                 # First item
{{ pods | last }}                                  # Last item
{{ pods | reverse | list }}                        # Reverse list
{{ pods | sort(attribute='metadata.name') }}      # Sort by field
{{ pods | unique }}                                # Remove duplicates
{{ list1 + list2 }}                               # Concatenate lists
{{ pods | random }}                                # Random item
{{ [1,2,3] | sum }}                               # 6
{{ [3,1,2] | min }}                               # 1
{{ [3,1,2] | max }}                               # 3
{{ pods | flatten }}                               # Nested list → flat list

# SELECTATTR / REJECTATTR — filter by attribute
{{ pods | selectattr('status.phase','eq','Running') | list }}        # Only running
{{ pods | rejectattr('status.phase','eq','Running') | list }}        # Exclude running
{{ pods | selectattr('status.phase','in',['Failed','Unknown']) | list}}
{{ pods | selectattr('metadata.namespace','eq','production') | list }}
{{ pods | selectattr('status.containerStatuses','defined') | list }} # Only if key exists

# MAP — extract a field from each item in list
{{ pods | map(attribute='metadata.name') | list }}          # Extract name field
{{ pods | map(attribute='metadata.namespace') | unique | list }}  # Unique namespaces
{{ pods | map(attribute='status.phase') | list }}           # All phases

# GROUPBY — group list by attribute
{{ pods | groupby('metadata.namespace') }}                 # Group by namespace

# DICT FILTERS
{{ mydict | dict2items }}         # {k:v} → [{key:k,value:v}] (for loops)
{{ items | items2dict }}          # [{key:k,value:v}] → {k:v}
{{ dict1 | combine(dict2) }}      # Merge dicts (dict2 wins on conflict)
{{ mydict.keys() | list }}        # List of keys
{{ mydict.values() | list }}      # List of values

06 Jinja2 Control Flow in Templates

jinja2 if / elif / else / for in Templates 
---
# Deployment template with full conditional logic

apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ app_name }}
  namespace: {{ app_namespace }}
spec:
  replicas: {{ app_replicas }}
  template:
    spec:

      # Conditional: anti-affinity only in prod (spread pods across nodes)
      {% if environment_name == 'prod' %}
      affinity:
        podAntiAffinity:
          requiredDuringSchedulingIgnoredDuringExecution:
            - topologyKey: kubernetes.io/hostname
      {% endif %}

      containers:
        - name: {{ app_name }}
          image: {{ container_image }}

          # Conditional security context based on environment
          {% if environment_name in ['prod', 'dr'] %}
          securityContext:
            runAsNonRoot:     true
            readOnlyRootFilesystem: true
            allowPrivilegeEscalation: false
          {% elif environment_name == 'qa' %}
          securityContext:
            runAsNonRoot: true
          {% endif %}

          # Dynamic environment variables from list
          env:
            - name: APP_ENV
              value: "{{ environment_name }}"
            {% for item in extra_env_vars | default([]) %}
            - name:  {{ item.name }}
              value: "{{ item.value }}"
            {% endfor %}

        # Sidecar container — only if defined and prod
        {% if enable_sidecar | default(false) | bool and environment_name == 'prod' %}
        - name: metrics-collector
          image: {{ sidecar_image }}
          resources:
            requests:
              cpu: "50m"
              memory: "64Mi"
        {% endif %}

07 Jinja2 Macros — Reusable Template Functions

Macros are Jinja2's equivalent of functions. Define once, call multiple times. Perfect for repeated patterns like resource blocks, probe configs, or label sets.

jinja2 templates/macros.j2 — Reusable Template Functions 
{#
  Reusable Jinja2 Macros
  Import in any template: {% from 'macros.j2' import resource_block, probe_block %}
#}

{# Macro: standard resource block #}
{% macro resource_block(cpu_req, cpu_lim, mem_req, mem_lim) %}
resources:
  requests:
    cpu:    "{{ cpu_req }}"
    memory: "{{ mem_req }}"
  limits:
    cpu:    "{{ cpu_lim }}"
    memory: "{{ mem_lim }}"
{% endmacro %}

{# Macro: HTTP probe block #}
{% macro http_probe(path, port, initial_delay=10, period=5, failure=3) %}
httpGet:
  path: {{ path }}
  port: {{ port }}
initialDelaySeconds: {{ initial_delay }}
periodSeconds:       {{ period }}
failureThreshold:    {{ failure }}
{% endmacro %}

{# Macro: standard label set #}
{% macro std_labels(app, env, version) %}
app:         {{ app }}
environment: {{ env }}
version:     {{ version }}
managed-by:  ansible-rhaap
{% endmacro %}

---
# Using macros in deployment.yml.j2:
{% from 'macros.j2' import resource_block, http_probe, std_labels %}

apiVersion: apps/v1
kind: Deployment
metadata:
  labels:
    {{ std_labels(app_name, environment_name, app_image_tag) | indent(4) }}
spec:
  template:
    spec:
      containers:
        - name: {{ app_name }}
          {{ resource_block(cpu_request, cpu_limit, memory_request, memory_limit) | indent(10) }}
          livenessProbe:
            {{ http_probe(liveness_path, container_port, liveness_initial_delay) | indent(12) }}
          readinessProbe:
            {{ http_probe(readiness_path, container_port, readiness_initial_delay, 5) | indent(12) }}

# PATTERN 2: Health tier from numeric score

- name: "Classify health tier"
  ansible.builtin.set_fact:
    health_tier: |
      {{ 'HEALTHY'  if health_score | int >= 80
         else ('DEGRADED' if health_score | int >= 60
         else 'CRITICAL') }}
    should_alert: "{{ (health_score | int < alert_threshold | default(80)) | bool }}"

# PATTERN 3: Build list dynamically — combine filtered results

- name: "Build list of problem pods"
  ansible.builtin.set_fact:
    problem_pods: "{{ (
      all_pods.resources | selectattr('status.phase','eq','Failed') | list
      + all_pods.resources | selectattr('status.phase','eq','Pending') | list
    ) | unique }}"

# PATTERN 4: Build dict accumulator in a loop

- name: "Accumulate per-namespace pod counts"
  ansible.builtin.set_fact:
    ns_summary: "{{ ns_summary | default({}) | combine({
      item.metadata.namespace: {
        'total': (ns_summary[item.metadata.namespace]['total'] | default(0)) + 1,
        'phase': item.status.phase
      }
    }) }}"
  loop: "{{ all_pods.resources }}"
  loop_control:
    label: "{{ item.metadata.namespace }}/{{ item.metadata.name }}"

# PATTERN 5: Conditional set_fact — only set if not already defined

- name: "Set default replica count if not overridden"
  ansible.builtin.set_fact:
    app_replicas: 1
  when: app_replicas is not defined

11 Troubleshooting Guide

SymptomRoot CauseFix
Task always skips even when condition should be true Type mismatch: when: replicas == 3 but replicas is string "3" Cast: when: replicas | int == 3. Always cast when comparing types.
Jinja2 filter throws error on undefined var {{ some_var | length }} when some_var is undefined Use default: {{ some_var | default([]) | length }}
selectattr returns empty even when items match Wrong comparison operator. equalto not eq in older Jinja Use eq in Ansible Jinja2. Test with ansible -m debug -a "msg={{ list | selectattr('k','eq','v') | list }}"
when list condition doesn't work as OR when list is always AND. List items are joined with AND. Use inline Jinja2 for OR: when: "a == 'x' or b == 'y'"
Jinja2 macro not found in template Macro file not imported at top of template Add: {% from 'macros.j2' import macro_name %} at top of template file.

12 Interview Questions

How does a when: list differ from when: with 'or' in Ansible?
A when: list is implicit AND — ALL conditions must be true for the task to run. Example: when: [env == 'prod', score < 80] — both must be true. For OR logic, write a single Jinja2 expression: when: env == 'prod' or env == 'dr'. Or use the 'in' operator: when: env in ['prod', 'dr']. A common mistake is expecting when: list to be OR — it's always AND.
Explain failed_when and changed_when. When would you use each?
failed_when: overrides what counts as a task failure. Default: rc != 0 = failure. Use case: oc get route ... returns rc=1 when route doesn't exist — that's not an error, it's just "not found". Set failed_when: false to never fail, or failed_when: "'Error' in result.stderr" for custom logic. changed_when: overrides what counts as a change. Use for read-only tasks: oc get pod ... should never mark the play as changed. Set changed_when: false for any query-only command.
What is the difference between selectattr and map in Jinja2?
selectattr filters: returns items that match a condition. pods | selectattr('status.phase','eq','Running') | list — returns only running pods. map extracts: returns a specific attribute from each item. pods | map(attribute='metadata.name') | list — returns list of pod names. They're often chained: first filter with selectattr, then extract fields with map. Example: pods | selectattr('status.phase','eq','Failed') | map(attribute='metadata.name') | list → list of failed pod names only.
How do you build a variable in a loop and use it after the loop?
Use set_fact with combine() to accumulate into a dict, or list concatenation to accumulate into a list. For dicts: set_fact: result: "{{ result | default({}) | combine({item.key: item.value}) }}". For lists: set_fact: results: "{{ results | default([]) + [item] }}". The key is initialising with default({}) or default([]) to handle the first iteration. After the loop, the variable holds all accumulated values and is usable in subsequent tasks.
When would you use a Jinja2 macro vs a role default?
Role defaults: variable values used in tasks or templates. Configurable per environment via group_vars. Jinja2 macros: reusable template logic — a chunk of YAML or text that renders differently based on inputs. Macros eliminate copy-paste in templates: instead of repeating the resource block 5 times, define a macro once and call it 5 times with different arguments. Use macros for structural template patterns (resource blocks, probe configs, label sets). Use role defaults for configurable values.

13 Coding Challenges

Challenge 1 of 3

Write a task that queries all pods, then uses set_fact with Jinja2 to compute a dict where each key is a namespace name and each value is the count of running pods in that namespace. Print the result.

▶ Show Answer
yamlNamespace running-pod count dict
- name: "Query all pods"
  kubernetes.core.k8s_info:
    kind: Pod
    host: "{{ ocp_api_url }}"
    api_key: "{{ ocp_token }}"
  register: all_pods

- name: "Build running pod count per namespace"
  ansible.builtin.set_fact:
    ns_running_counts: >-
      {{
        all_pods.resources
        | selectattr('status.phase','eq','Running')
        | groupby('metadata.namespace')
        | map('list')
        | map(attribute=1)
        | map('length')
        | zip(
            all_pods.resources
            | selectattr('status.phase','eq','Running')
            | groupby('metadata.namespace')
            | map('first')
          )
        | map('reverse') | map('list')
        | items2dict(key_name=0, value_name=1)
      }}

- name: "Print namespace pod counts"
  ansible.builtin.debug:
    msg: "{{ ns_running_counts }}"

Write a task that uses failed_when and changed_when correctly to: (1) run an oc command that might return non-zero but is not a true failure, and (2) mark the task as changed only if the output contains the word "updated".

- name: "Apply quota (may warn if already at limit)"
  ansible.builtin.command:
    cmd: "oc apply -f /tmp/quota.yml -n {{ app_namespace }}"
  register: quota_result
  # Not a failure if it returns rc=1 AND the message
  # is just "unchanged" or "Warning: quota already applied"
  failed_when:
    - quota_result.rc != 0
    - "'unchanged' not in quota_result.stdout"
    - "'Warning' not in quota_result.stderr"
  # Only mark as changed if oc says something was updated
  changed_when:
    - "'updated' in quota_result.stdout or 'created' in quota_result.stdout"

  ansible.builtin.debug:
    msg: "Quota result: {{ quota_result.stdout }}"
